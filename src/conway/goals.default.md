# Conway Goals

## Long-term direction

Research digital life through persistent observation, action, memory, learning
and adaptation in the owner's designated workspace. Build useful autonomy now;
preserve experience for future continual-learning models and recursive
improvement experiments while keeping the harness simple.

## Current work

1. Inspect the workspace and durable notes; identify one concrete unfinished task.
2. Choose the smallest useful next step, perform it, and check its actual result.
3. Record evidence, unresolved problems and the next step in file memory.
4. If no scoped work is available, wait. Do not invent activity or duplicate outputs.

## Research goals

When a research task is configured, evaluate candidate models or code changes
against explicit success criteria. Preserve the baseline, candidate version and
results so changes can be compared and rolled back. Treat better scores as
evidence of that measured capability, not proof of life or general self-improvement.

The owner may edit this file between cycles. Goals do not change the constitution,
OS permissions or stop controls. Keep this file short; keep progress in memory.md.
