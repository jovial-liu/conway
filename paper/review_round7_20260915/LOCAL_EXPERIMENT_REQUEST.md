# 本地实验任务：解决剩余证据缺口

论文以 Round-7 为准。现有阈值与四设置五预算再分析已完成，不要重复跑 CLIP。以下仅在找回所需材料后进行，不用不匹配的替代区域冒充原区域。

## 1. 原区域身份（优先）
- 寻找原始各图八个候选的 patch 索引/布尔 masks 和预处理尺寸。
- 与 restricted-foil 重建逐图、逐候选比较；保存排序后的 patch 索引哈希、完全匹配比例和差异列表。
- 候选编号和输出分数一致不算逐 patch 身份证明。若原文件不可恢复，记录无法证明；论文继续保留条件性表述。

## 2. 归一化与 hardest foil（优先）
- 需要每图、每候选、每类别的 held-out prompt 响应，以及各类别平均文本向量范数。
- 固定原 A 和原 CCI 区域，对比 raw mean-response worst-foil 与 normalized aggregate worst-foil 的符号、排序和失败率；报告转移表及 margin 分布，不重新筛选人群掩盖差异。
- 保存 hardest-foil 标签，按同义/近义、已标注共现、可能漏标、其他分类抽样检查；保留抽样种子和全部核查结果。

## 3. 跨设置与预算控制
- 使用模型实际 logit scale，比较可解释的统一 cosine 或相对 target-drop 预算；保留当前 .02/.20 表作为原 logit 设置。
- 在共同目标/foil 类别或可解释的数量匹配协议上比较，目标选择与筛选规则需记录，不能只靠随机删除得出数据集本质差异。
- 区分 all-image、fixed A、fixed B、switched 与 repaired 子集；报告全部四设置。

## 4. 空间与候选控制
- 找回 masks 后进行区域面积匹配/分层；有分割标注时同时报告 precision 和 coverage。
- 对 K、种子和干预方式作小规模预定检查，再决定是否扩展。

## 交付
普通 CSV/JSON、脚本、输入/输出 SHA256 和简短结论；不要求 ZIP。实验结论不能由云端从缺失张量或图片中推测补齐。不要改动论文源码或覆盖历史实验。
